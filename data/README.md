# 菜单快照

`catalog_meituan.json` 为清洗后的美团菜单采集记录，用于复现原型的推荐体验。参考区域：复旦大学北苑学生生活园区；菜单采集于 2026-11-02，商户配送信息为同日稍后的快照。

132 条正餐记录来自 17 家商户。42 条可参与预算等初筛，其余 90 条所有规格在采集时库存为零，保留记录但暂不推荐。字段口径与限制见[菜单接入说明](../docs/本地菜单接入.md)。

本文件不包含 API Key、个人账号、聊天、图片或原始采集文件。商户名和商品名保留来源名称；应用与美团无官方隶属关系，不提供实时查询或下单功能。仓库 MIT 许可针对项目代码，不表示对第三方商标、图片或原始平台内容授予额外权利。
