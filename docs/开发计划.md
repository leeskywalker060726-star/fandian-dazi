# 饭点搭子开发计划

由 Codex 负责开发，按可运行里程碑推进。开发开始日期为 2026 年 11 月 4 日。

## 当前约束

本机使用 Python 3.13 和 Node 24。用户补充了 MySQL 路径，现已成功连接 MySQL Community Server 26.10.0；npm 安装于项目本地工具目录。后端兼容 MySQL 与 SQLite，当前使用用户配置的 MySQL。真实 DeepSeek 工具调用与 MCP 已完成联调。Docker 尚未检测到。

## 验收原则

每个里程碑均保留可运行状态；推荐数据来自种子目录，所有演示数据明确标注。重点检查数据隔离、硬约束、临时记忆过期、重复请求以及删除记忆后的推荐行为。没有实际运行的 MySQL 或外部模型接入不能记作已验证。
