# 饭点搭子 Windows 桌面版

## 下载与启动

在 GitHub Releases 下载 `FandianDazi-0.3.0-windows-x64.zip`，解压整个文件夹，双击 `FandianDazi.exe`。不要单独移动 exe，旁边的 `_internal` 和 `FandianWorker.exe` 都是运行所需文件。

支持 Windows 10/11 x64，需要 Microsoft Edge WebView2 Runtime。多数 Windows 电脑已自带；缺少时请从 [Microsoft 官方页面](https://developer.microsoft.com/microsoft-edge/webview2/) 安装。无需 Python、Node、MySQL 或管理员权限。当前为免安装版，尚未购买代码签名证书；请核对发布者、版本和 SHA256，不要关闭系统安全保护。

首次使用可选择访客体验或注册本地账号，完成口味设置后进入首页。

## 连接聊天模型

应用不内置 API Key。点击右上角“连接聊天模型”（配置后为“模型设置”），填写兼容 Chat Completions 的服务地址、模型名称与自己的 API Key。DeepSeek 示例：服务地址 `https://api.deepseek.com`，模型 ID `deepseek-flash`；不要额外添加 `/chat/completions`。保存后下一条消息生效。未配置模型时仅为基础规则体验。桌面版不会读取开发项目 `.env` 或继承模型密钥环境变量，首次使用必须自行在 App 内配置。

密钥通过 Windows DPAPI 加密，绑定当前 Windows 用户。更换电脑或系统用户时需重新填写密钥。填写模型服务代表聊天会将当前消息、有限对话上下文和已确认有效记忆发送至该服务；请选用自己信任的服务商。

## 数据与退出

桌面版与开发网页版的数据相互独立。数据保存在 `%LOCALAPPDATA%\FandianDazi`，包括 SQLite 数据库、加密模型设置与启动日志。记忆页支持删除个人资料与导出记忆。账号数据删除不会清除应用级模型配置，密钥需在模型设置中单独清除。

关闭窗口即关闭本次启动的本地服务。后端只监听随机的 127.0.0.1 端口，并校验每次启动的桌面会话密钥，不监听局域网。应用暂不提供自动更新；升级时替换解压后的程序目录，数据目录仍保留。

## 源码构建

在 Windows x64 安装 Python 3.13、Node.js 24，然后运行：

```powershell
.\scripts\build-desktop.ps1
```

输出位于 `release/`，包含可运行目录、ZIP 和 SHA256 校验文件。构建使用固定 Python 依赖与 npm lockfile。前端来自 `dist`，打包配置采用文件白名单，不包含 `.env`、数据库或聊天记录。

开发调试：`.venv\Scripts\python.exe -m desktop.main`。可用 `FANDIAN_DATA_DIR` 指定隔离的数据目录。`FandianDazi.exe --smoke-test` 运行无界面的打包集成测试并写入 `smoke-result.json`，仅创建并清理测试账号。

## 原型边界

v0.3.0 新安装默认使用随包附带的清洗菜单快照，也支持[导入其他本地采集菜单](本地菜单接入.md)；原 v0.2.0 不支持快照。快照会明确标注日期和未知信息，实际营业与库存需确认。路线、天气与用餐耗时假设仍为演示；选择餐食不下单。暂不提供医疗、过敏安全或营养保证。已支持多轮聊天、段落记忆、确定性选餐和 MCP，尚未实现 RAG、实时外卖接口、跨设备同步、自动升级和数字签名。
