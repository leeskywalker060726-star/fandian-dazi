# 首版原型验证记录

验证日期：2026 年 11 月 4 日。运行环境：Windows、Python 3.13、Node 24、MySQL Community Server 26.10.0。

## 自动检查

- 前端 TypeScript 检查与 Vite 生产构建通过。
- `pytest -q`：19 项通过。测试使用隔离 SQLite 数据库，结束后清理自身测试文件，不使用用户 MySQL 数据。
- 测试覆盖：硬预算、忌口、多轮条件保留、换商户、临时记忆到期、长期恢复、删除后不从旧消息恢复、用户隔离、幂等请求、版本冲突、选择与实际用餐分离、记忆关闭、否定范围、不同分句的有效期、夜间营业、SSE 和账号数据删除。
- 测试依赖 Starlette 有一条 httpx 测试客户端弃用提示，不影响当前通过结果，后续升级时处理。

## 真实服务联调

运行 `scripts/live_smoke.py` 验证：数据库类型为 mysql，目录调用路径为 mcp，模型调用模式为 llm。实际完成 DeepSeek 结构化工具调用、MySQL 保存、MCP 查询、餐食选择、用餐反馈与 Skill ZIP 导出。

“这周每顿最多15，以后别推奶茶”分别产生本周预算和长期奶茶排除偏好。脚本使用专门创建的临时账号，在结束后只删除该账号的数据。

## 浏览器检查

在本地浏览器完成访客进入、标签设置、推荐、编辑记忆有效范围、新会话继承偏好、选择餐食、记录反馈与实际金额。选择后确认吃过的数量保持为零，提交反馈后变为一；实际支出从零变为录入金额。

检查了 1366 像素桌面布局与 390 像素移动布局；移动页面内容宽度与视口均为 390 像素，无横向溢出。最后检查的浏览器控制台没有错误。临时视口覆盖已恢复。
